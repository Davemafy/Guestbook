# Guestbook External Evidence

The first synthetic-only Guestbook model looked strong on its 35-case frozen prototype benchmark but failed to generalize: on an external 5,000-review Nairobi stress sample it abstained on 79.8% of inputs, and its mapped-label hit rate on the untouched MASSIVE Swahili test probe was only 0.3%.

That failure was used as a stop signal. The production model was retrained with external **training partitions only**, then frozen again before the test partitions were evaluated.

## Production training mix

Total: **2,687 training cases**

- **438** bundled synthetic prototype cases
- MASSIVE train examples:
  - WANT_BOOKING: **440**
  - WANT_PRODUCT: **270**
  - ASK_ACCESS: **640**
- Nairobi weak-supervision train examples:
  - PRAISE_EXPERIENCE: **320**
  - RETURN_REFERRAL: **320**
  - FRICTION_EXPECTATION: **50**
  - FRICTION_VALUE: **100**
  - FRICTION_ACCESS: **109**

The Nairobi split is deterministic by text hash. The held-out bucket is never used to fit the production weights.

## Frozen synthetic regression set

At threshold **0.60** on 35 bundled cases:

| Metric | Result |
| --- | ---: |
| Micro precision | **92.5%** |
| Micro recall | **88.1%** |
| Micro F1 | **90.2%** |
| Exact multi-label match | **82.9%** |

The production model intentionally gives up some synthetic-demo score in exchange for substantially better external generalization.

## MASSIVE untouched test probe

MASSIVE is not a tourism dataset. We map a small set of source intents to the nearest Guestbook signals, so this is a **semantic-transfer probe**, not tourism field accuracy.

| Locale | Test cases | Mapped-label hit |
| --- | ---: | ---: |
| English (en-US) | 305 | **91.1%** |
| Kiswahili (sw-KE) | 305 | **92.8%** |

Swahili test details:

| MASSIVE intent | Guestbook signal | Cases | Hit |
| --- | --- | ---: | ---: |
| calendar_set | WANT_BOOKING | 209 | **93.8%** |
| takeaway_order | WANT_PRODUCT | 22 | **86.4%** |
| transport_query | ASK_ACCESS | 51 | **90.2%** |
| transport_taxi | ASK_ACCESS | 23 | **95.7%** |

The test split is not used for training.

## Nairobi held-out weak-label probe

Source: Inside Airbnb Nairobi detailed reviews, 15 June 2026.

The source contains **138,300 reviews**. Guestbook creates transparent lexical anchors for a narrow set of obvious signals, hashes sentences into train/held-out partitions, trains only on the training partition, and evaluates agreement on held-out anchor-matched sentences.

| Signal | Held-out cases | Label agreement |
| --- | ---: | ---: |
| PRAISE_EXPERIENCE | 500 | **98.4%** |
| RETURN_REFERRAL | 500 | **97.8%** |
| FRICTION_VALUE | 23 | **95.7%** |
| FRICTION_ACCESS | 23 | **95.7%** |
| FRICTION_EXPECTATION | 9 | **100%** |
| **Overall** | **1,055** | **98.0%** |

These are **weak labels generated by explicit lexical rules**, not manual field annotations. High agreement shows that the compact model can carry recognizable signals across human-written tourism/hospitality language; it does not establish field accuracy.

## Licensing and data handling

- **Amazon MASSIVE v1.1** — CC BY 4.0. English and Swahili (Kenya) train/test partitions are used for the semantic-transfer experiment.
- **Inside Airbnb Nairobi** — the public download page states CC BY 4.0. Inside Airbnb asks users to attribute the project and avoid republishing raw data.

Guestbook downloads raw external data only inside the evaluation/training job. Raw external reviews are **not committed or republished** in this repository.

## Remaining evidence gap

A real deployment still needs an independently collected, consented, human-labeled dataset from target tourism operators and visitors, with per-label precision/recall, abstention coverage, correction rates, and low-end Android latency measured before operational use.
